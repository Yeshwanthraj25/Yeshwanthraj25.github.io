Judge-and-rewrite pipeline

Proof of concept

A client’s platform could remove bias from news articles, but the output read like obvious AI writing. I built the backend for a serverless loop on AWS Lambda where two models score a draft, rewrite it, and re-score it until it passes or reaches an iteration cap.

Every iteration is stored in its own table, so one GET request replays an article’s whole history. When Lambda started timing out, I swapped Opus 4 for Claude 4.5 and ran both models in parallel. A run dropped from about 60 seconds to 12.

Built with Python, AWS Lambda, Bedrock (Claude 4.5, OpenAI OSS), Prompt Manager, PostgreSQL and ThreadPoolExecutor.

Engineering performance dashboard

In production at Avasoft

Leadership had no single view of how engineers and teams were loaded across sprints. I built the Individual Performance and Allocation modules on FastAPI and PostgreSQL, and the Microsoft Graph sync that keeps roles and departments current for about 1,400 employees.

Allocation is flagged Healthy, Warning or Over-allocated, and overloaded people get a suggested redistribution, because leaders needed something to act on, not just a number.

Built with FastAPI, PostgreSQL, Microsoft Graph API, Jira API and Azure DevOps.

Employee Attendance and Leave API

Personal project

A REST API for tracking attendance (check-in and check-out) and managing leave requests. It uses JWT authentication with three roles, admin, manager and employee, with access tokens that last 15 minutes and refresh tokens that last 7 days.

The data model has six tables: employees with a department and a manager link, departments, attendance logs, leave requests, yearly leave quotas and an error log. The code is layered into routes, services and repositories, with Alembic migrations written alongside the models, a uniform response format, and a route-level error handler that writes failures to the database.

Along the way I fixed type mismatches between async SQLAlchemy and Pydantic, a password hashing compatibility error, and a test suite that failed on foreign keys and wrong status codes until I fixed its shared database fixtures. It is not deployed yet and has no rate limiting.

Built with FastAPI, async SQLAlchemy, PostgreSQL, Alembic, Pydantic, pytest, Docker and uv.

RAG Job Assistant

In progress

An API where you upload documents, ask questions, and get answers with source citations, or a refusal when the documents don’t say. Documents are split into chunks, turned into embeddings and stored in PostgreSQL with pgvector, and the model answers from what retrieval returns.

I compared fixed and recursive chunking on a 10-question evaluation set, then rewrote the prompt to remove two failures: answers that mixed up people across documents, which I fixed by labelling every source, and answers that went beyond what the documents said. I also swapped the model provider behind a client layer when credits ran out.

The test set is small, there is no authentication yet, and the tests are still to write. Next are chat history, citation filtering, and a LangGraph agent that compares a resume with a job description.

Built with FastAPI, PostgreSQL, pgvector and Cloudflare Workers AI.
